# Construtecn

Site institucional da Construtecn (construtora em Brasilia-DF).
Identidade visual atualizada, obra em destaque (Edificio Dona Branca), obras comercial e residencial e contato.

## Estrutura

- `index.html` pagina unica, autossuficiente
- `assets/` imagens, logo, poster e video

## Deploy

Site estatico. Basta servir a pasta. Funciona em GitHub Pages, Cloudflare Pages, Netlify ou qualquer hospedagem estatica.

## Observacoes

- Formulario de contato envia a mensagem via WhatsApp (61) 99830-4660
- Fotos de obra comercial/residencial sao temporarias (recortadas de prints); substituir pelas originais em alta
